# Credits, provenance and scope

The branding, channel artwork, thumbnails, English subtitle files and nine PDF reports were supplied by the project owner in `youtube_EN_final_materials_2026-09-09.zip`. Selected subtitle files are retained under `sources/transcripts/`; the input manifest, selection decisions and archive checksum are retained under `sources/`.

The website layout, generator, styles, progressive-enhancement JavaScript, rewritten articles, data visualizations and documentation were prepared for this Armwrestling LAB project. No website theme, stock-photo package, icon font or external font is bundled. Small inline SVG interface icons and chart markup are part of the project code. The operating system supplies system fonts.

Article bibliographies identify the scientific publications used as evidence. Publication titles and citation metadata remain in their source language. Supplied PDFs are copied without modification. The source image versions were resized/re-encoded for website performance. Some channel artwork includes people or third-party visual elements from the supplied files; this package does not independently verify or extend rights to those materials.

No new blanket public license is imposed on the channel brand, source media, reports, transcripts or scientific publications. The owner should choose any intended repository/code/content license and confirm rights to supplied media before granting reuse to others. A public repository by itself is not described here as making those materials public-domain.

No OpenAI credentials, GitHub tokens, personal inbox data, font files or remote tracking libraries are included.
